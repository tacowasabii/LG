ffmpeg를 전제로 쓴다. 브라우저 실시간 녹화가 아니라 스크립트에서 mp4로 구우면 된다.

| | 예전 견적 (canvas+MediaRecorder) | 지금 (ffmpeg 스크립트) |
|---|---|---|
| 시간 | 45초 영상 = 45초 대기 | 실시간보다 빠름 |
| 코덱 | webm — 아이폰 사파리 재생 불가 | h264 mp4 — 어디서나 |
| 자막·내레이션 | canvas에 직접 그려야 함 | ffmpeg 필터로 |

대신 fal과 같은 성격이 된다 — 사람이 미리 굽고 결과를 커밋한다. 화면에서 버튼을
눌러 만드는 것이 아니다. 이 저장소가 이미 택한 패턴이라 오히려 일관된다.

## C. 여기서는 안 한다 — 이유를 적어 둔다

| 항목 | 왜 |
|---|---|
| AI Vision **얼굴 인식** | Bedrock이 붙었지만 그래도 안 한다. 범용 VLM으로 "이 사람이 김민수다"를 판정하는 것은 정확도가 아니라 성격의 문제다 — 가족 구성원 식별은 생체정보이고, 틀리면 남의 사진에 엉뚱한 사람이 붙는다. A1(사람이 직접 지목)이 이 제품에 맞는 답이다 |
| 지도 SDK (Leaflet/Mapbox) | 타일 네트워크·키·비용. A4로 버틴다 |
| webOS 실기기 | 기기·인증서 없음. [remote.ts](../frontend/src/lib/remote.ts)에 교체 지점만 남겨 둔다 |
| Export 작업 큐 | 시드 26MB에서 즉시 끝난다 ([export.py:3-5](../backend/routers/export.py#L3-L5)) |
| 벡터 검색 | 키워드 가중치로 goldset을 통과하고 있다 |
| Trust 화면에서 채점 실행 | 의도한 설계다. `POST /api/trust/run`은 있지만 몇 분 걸려서 화면에 안 붙였다 ([trust.py:3-5](../backend/routers/trust.py#L3-L5)) |
| 로그인 · 인증 | **하지 않기로 정했다 (2026-08-21).** 세션·토큰·비밀 관리가 따라오고 발표에 주는 값이 가장 작다.<br>남는 사실은 적어 둔다 — 이 API에는 인증이 없다. 역할 가드와 공개 범위는 화면에서의 실수를 막는 수준이고([permissions.py:6](../backend/services/permissions.py#L6): *"이것은 보안 경계가 아니다"*), 주소를 아는 사람은 `curl`로 가족 기록을 읽고 쓸 수 있다. 배포를 공개해 둘 때 이 점을 알고 있어야 한다.<br>붙일 자리는 이미 좁혀져 있다: `permissions.current_actor()`가 헤더 대신 토큰에서 사람을 읽으면 아래 규칙은 그대로 쓸 수 있고, [currentUser.tsx](../frontend/src/lib/currentUser.tsx)는 localStorage 대신 세션을 읽는다 |
