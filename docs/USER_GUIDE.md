# LG HomeStory 사용법

화면 16개를 무엇부터 어떤 순서로 쓰는지, 각 화면이 실제로 무엇을 하는지 적었습니다.
설계 근거는 `MVP_DESIGN.md`, API 호출 형식은 `SPEC_SUMMARY.md`를 보세요.

---

## 1. 준비

### 이미 띄워진 주소로 접속하는 경우
브라우저에서 주소를 열면 끝입니다. 시드 데이터(사건 8개 · 사진 24장)가 이미 들어
있으므로 바로 홈 타임라인이 보입니다.

### 직접 실행하는 경우

```bash
# 백엔드
source venv/bin/activate
python scripts/seed_from_metadata.py     # 처음 한 번 — 그래프 생성
python scripts/generate_profiles.py      # 처음 한 번 — 인물 프로필 크롭
uvicorn backend.main:app --reload --reload-exclude "venv/*" --port 8000

# 프론트엔드 (다른 터미널)
cd frontend && npm run dev               # → http://localhost:5173
```

`.env`에 `EXAONE_API_KEY`가 없어도 동작합니다. 다만 채팅·인터뷰·TV 자막의 문장이
LLM 대신 시뮬레이션 응답으로 나오므로, 실제 답변 품질을 보려면 키를 넣으세요.

---

## 2. 화면 배치

왼쪽 사이드바가 다섯 묶음으로 나뉘어 있고, 순서가 곧 사용 흐름입니다.

| 묶음 | 화면 | 하는 일 |
|------|------|---------|
| **기억** | 홈 · 타임라인·지도 · 그래프 · 인물 | 이미 쌓인 것을 본다 |
| **모으기** | 시작하기 · 업로드 · AI 인터뷰 | 새 기록을 넣는다 |
| **확인** | 확인 요청 · Memory Gap | AI가 추정한 것을 가족이 판정한다 |
| **경험** | 채팅 · Memory Film · TV | 쌓인 기억을 꺼내 쓴다 |
| **가족** | 가족 공간 · 공개·동의 · 내보내기 · 신뢰도 리포트 | 권한과 신뢰를 관리한다 |

### 지금 사용 중인 사람 — 먼저 확인하세요

사이드바 맨 위 이름 카드를 누르면 가족 구성원 중 누구로 쓸지 고를 수 있습니다
(로그인이 아직 없어서 화면에서 고릅니다). 이 선택이 다음 세 가지를 바꿉니다.

- **인터뷰 답변의 주인** — 남긴 기억이 그 사람의 기억으로 귀속됩니다
- **확인 판정의 주체** — 사건을 "맞음"이라고 한 사람이 누구인지 기록됩니다
- **보이는 기록의 범위** — 그 사람이 볼 수 없는 원본은 목록·검색·채팅 근거에서 빠집니다

같은 사건이 사람에 따라 다르게 보이는 것이 정상입니다. 버그가 아닙니다.

## 3. 처음 10분 — 첫 기억 만들기

가장 짧은 경로는 **시작하기 → 확인 요청 → 채팅** 입니다.

1. **시작하기**(`/onboarding`) — 사진을 최대 3장 고릅니다. 네 단계(사진 고르기 →
   읽는 중 → 첫 질문 → 첫 기록 완성)를 그대로 걸으면 사건 하나가 만들어집니다.
   업로드는 실제로 일어나고, 이어지는 질문도 실제 인터뷰 세션입니다.
2. **확인 요청**(`/verify`) — AI가 추정한 날짜·장소·참여자를 맞음/모름/이견으로 판정합니다.
3. **채팅**(`/chat`) — 방금 넣은 사건을 물어봅니다. 답변 아래 근거 썸네일이 붙습니다.

## 4. 화면별 사용법

### 기억

**홈** (`/`)
연도순 타임라인입니다. 사건 줄을 누르면 그 사건에 붙은 사진이 펼쳐집니다. 위쪽에
사건·사진·기억 개수와 가족이 남긴 목소리가 함께 나옵니다.

**타임라인 · 지도** (`/map`)
인물과 연대(1990/2000/2010/2020년대)로 걸러 봅니다. 화면 폭을 가로지르는 필터 띠에서
조건을 고르면, 아래 지도에 사건이 연도순 이동 경로로 이어집니다. 좌표가 없는 사건은
지도에 찍히지 않습니다.

**그래프** (`/graph`)
노드를 끌어 관계를 탐색합니다. 색이 종류입니다 — 인물(잉크) · 사건(강조색) ·
장소(teal) · 기록(연회색) · 기억(보라). 선은 확인된 관계가 진하고 AI 추정이 옅습니다.
노드를 누르면 오른쪽에 상세가 열립니다.

**인물** (`/family`)
구성원 목록입니다. 카드를 누르면 그 사람이 참여한 사건과 남긴 목소리가 보입니다.
아래 폼으로 이름·관계·출생연도만 넣어 인물을 새로 추가할 수 있습니다.

### 모으기

**업로드** (`/upload`)
사진·영상·음성을 끌어다 놓거나 눌러서 고릅니다. 올리면 파일마다 **읽은 결과**가
알약 한 줄로 나옵니다 — 촬영 시점, GPS, 연결된 사건.

`추가 정보 필요`가 뜨면 EXIF가 없는 파일입니다. 오류가 아니고, 서비스가 날짜를
추측하지 않는다는 뜻입니다. 그 자리에서 날짜를 적거나 기존 사건에 연결하고 설명을
남기면 그래프에 반영됩니다.

**AI 인터뷰** (`/interview`)
세션당 질문 5개입니다. 답하는 방법이 둘입니다.

- **글로** — 입력창에 적습니다
- **말로** — 녹음 버튼을 누릅니다. 마이크 권한이 필요하고, 길이·파형이 함께 저장됩니다

녹음한 목소리는 원본으로 보관되지만 **자동 전사(음성→글)는 아직 없습니다.** 말로 답한
뒤에도 내용은 화면에서 직접 적어야 그래프에 문장으로 들어갑니다.

### 확인

**확인 요청** (`/verify`)
AI가 연결한 사실을 사건별로 확인합니다. 구성원 줄마다 버튼이 셋입니다.

| 판정 | 결과 |
|------|------|
| 맞음 | 사건이 확인 상태로 올라갑니다 |
| 모름 | 답하지 않았음을 남깁니다 (사건은 추정으로 유지) |
| 이견 | 메모를 적으면 기존 기록을 **덮지 않고** 그 사람의 다른 기억으로 함께 보존합니다 |

사이드바 "확인 요청" 옆 숫자가 아직 추정이거나 기억이 갈린 사건 수입니다.

**Memory Gap** (`/gaps`)
빠진 정보를 여섯 종류로 찾아 줍니다 — 날짜 없음 · 장소 없음 · 설명 없음 · 기록 없음 ·
참여자 없음 · 한쪽 관점. 카드에 무엇을 물어야 하는지가 함께 적혀 있고, 거기서 인터뷰나
업로드로 넘어갑니다.

### 경험

**채팅** (`/chat`)
"우리 가족이 부산 처음 간 게 언제야?" 처럼 자연어로 묻습니다. 처음 열면 예시 질문
네 개가 있으니 그것부터 눌러 보세요.

답변 아래에 두 가지가 붙습니다.

- **근거 썸네일** — 누르면 원본 패널이 열립니다. 사건에 가족 목소리가 있으면 함께 재생됩니다
- **신뢰도 문장** — 아이콘이 아니라 문장으로 밝힙니다

| 표시 | 뜻 |
|------|-----|
| 확인된 기록 기반 | 가족이 확인한 사건 |
| 두 사람 이상의 기억으로 뒷받침됨 | 여러 관점이 같은 방향 |
| 기억이 갈리는 사건 · 양쪽 보존 | 이견이 있는 사건 |
| AI 추정 포함 · 아직 확인되지 않았습니다 | 확인 필요 |
| 근거 없음 · 추측하지 않았습니다 | 기록이 없어 답하지 않음 |

마지막 두 경우에는 답변 아래에 기억을 남기거나 확인하러 가는 링크가 붙습니다.

**Memory Film** (`/film`)
사건 하나를 골라 길이(30/45/60초)와 대상을 정하면 장면이 구성됩니다.

| 대상 | 차이 |
|------|------|
| 아이용 | 쉬운 낱말, 짧은 문장, 인물 이름을 자주 부름 |
| 성인용 | 사건의 배경과 관계를 설명 |
| 어르신용 | 전환을 늦추고 당시 호칭을 그대로 씀 |

장면마다 원본 출처와 적용된 효과가 표시됩니다 — `원본 그대로`(teal)와 `움직임
효과`(보라). 인물·행동을 새로 만들지 않고 패닝·줌만 씁니다. **이 화면은 장면 구성
미리보기이고, 영상 파일로 렌더하지는 않습니다.**

**TV** (`/tv`)
거실 TV를 가정한 풀스크린 화면입니다. 마우스 대신 키보드로 조작합니다.

| 리모컨 | 키보드 |
|--------|--------|
| ◀ ▶ ▲ ▼ | 화살표 |
| OK | Enter |
| BACK | Esc 또는 Backspace |
| 재생/일시정지 | Space |

화면은 셋뿐입니다.

1. **대기화면** — 오늘의 기억이 먼저 뜹니다. OK로 바로 보고, ▼로 메뉴에 들어갑니다
2. **메뉴** — 프리셋 6개(가장 오래된 기억, 특정 장소에서 보낸 날들 등). 검색창은 없습니다
3. **재생** — ◀ ▶로 장면 이동, Space로 정지. **OK를 누르면 근거 화면**이 열려 원본·촬영
   시점·출처를 보고 가족 목소리를 재생할 수 있습니다

### 가족

**가족 공간** (`/space`)
구성원의 역할을 정하고 새 사람을 초대합니다.

| 역할 | 할 수 있는 일 |
|------|--------------|
| 가족 관리자 | 초대, 공개 범위, 삭제·이관 결정 |
| 기록자 | 기록 올리기, 기억 남기기, 확인 참여 |
| 열람자 | 보고 듣기만 (기록을 바꾸지 않음) |
| 초대 대기 | 링크를 보냈고 아직 참여하지 않음 |

초대 버튼을 누르면 코드가 나옵니다. **유효 기간 72시간**입니다.

**공개 · 동의** (`/privacy`)
세 가지를 조작합니다.

1. **기록별 공개 범위** — 파일마다 `가족 전체` / `일부 가족` / `개인 전용`을 고릅니다.
   새로 올린 기록의 기본값은 가족 전체입니다
2. **삭제 영향** — 원본을 지우면 무엇이 함께 사라지는지 미리 봅니다. 가족이 남긴 기억
   문장은 지워지지 않고 원본과의 연결만 끊깁니다
3. **인물별 비공개 요청** — 사진 속 인물이 원하면 그 사람이 등장하는 기록을 가족
   공유에서 뺍니다. 원본은 남고, 본인은 계속 봅니다

여기서 바꾼 값은 저장만 되는 게 아니라 목록·검색·채팅 근거에서 실제로 가려집니다.

**내보내기** (`/export`)
받아갈 항목을 골라 zip을 만듭니다 — 원본 사진·영상 / Memory Graph / 목소리와 전사문 /
가족 연대기(HTML). 용량은 서버가 디스크에서 잰 실제 값이고, 아카이브도 실제로 생성됩니다.

**신뢰도 리포트** (`/trust`)
정답표(`data/goldset.json`)로 실제 질의를 돌려 채점한 결과를 봅니다. 문항별로 통과 /
부분 / 실패와 사유가 적혀 있습니다.

채점은 문항마다 LLM 호출이 들어가 수 분 걸리므로 **화면에서 실행하지 않습니다.**
미리 돌려 두세요.

```bash
python scripts/run_trust_harness.py            # 20문항 전체
python scripts/run_trust_harness.py --limit 5  # 앞 5문항만
```

결과는 `data/trust_report.json`에 저장되고 화면이 그 파일을 읽습니다.

## 5. 공개 범위가 실제로 어떻게 적용되는가

모든 조회에 "지금 사용 중인 사람"이 함께 나가고, 서버가 그 사람이 볼 수 없는 원본을
빼서 내려줍니다. 목록 · 사건 요약의 썸네일 · 인물 상세 · 채팅 근거 검색이 모두 같은
판정을 지납니다.

| 범위 | 누가 보는가 |
|------|------------|
| 가족 전체 | 참여한 구성원 모두 (새 기록의 기본값) |
| 일부 가족 | 고른 사람과 소유자 |
| 개인 전용 | 올린 사람만 |

여기에 인물 동의가 겹칩니다. 어떤 인물이 비공개를 요청하면 그 사람이 등장하는 기록이
다른 가족에게 가려지고, 본인은 계속 봅니다.

## 7. 막혔을 때

| 증상 | 원인과 대처 |
|------|------------|
| 화면이 전부 비어 있다 | 시드를 안 돌렸습니다. `python scripts/seed_from_metadata.py` |
| 올린 사진에 "추가 정보 필요" | EXIF가 없는 파일입니다. 정상 동작이고, 그 자리에서 날짜를 적으면 됩니다 |
| 채팅이 "근거 없음"만 답한다 | 그 사건의 기록이 없습니다. 인터뷰나 업로드로 채우세요 |
| 답변이 짧고 뻔하다 | `EXAONE_API_KEY`가 없어 시뮬레이션 응답입니다 |
| 답변이 오래 걸린다 | 추론 모드입니다. `.env`에서 `EXAONE_ENABLE_THINKING=false` |
| 녹음이 안 된다 | 마이크 권한을 거부했거나 HTTP(비보안) 주소입니다. localhost나 HTTPS에서 쓰세요 |
| 분명히 있던 사진이 안 보인다 | 지금 사용 중인 사람의 열람 범위 밖입니다. 사이드바에서 사용자를 바꿔 확인하세요 |
| 신뢰도 리포트가 비어 있다 | 하네스를 돌리지 않았습니다. `python scripts/run_trust_harness.py` |
| TV 화면에서 키가 안 먹는다 | 화면을 한 번 클릭해 포커스를 주세요 |

## 8. 발표용 진행 순서

1. **홈** — 연도순 타임라인, 사건 하나 펼쳐 사진 보기
2. **타임라인 · 지도** — 인물 필터를 걸어 이동 경로 보기
3. **그래프** — 인물 노드에서 사건으로 관계 따라가기
4. **채팅** — "우리 가족이 부산 처음 간 게 언제야?" → 근거 썸네일 열기
5. **Memory Gap** — 한쪽 관점만 남은 사건 지적
6. **AI 인터뷰** — 그 빈 곳을 질문으로 받아 답변 남기기 (사용자 전환도 함께 보여주기)
