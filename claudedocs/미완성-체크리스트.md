# 미완성 기능 체크리스트

2026-08-20 코드 조사 결과. 위에서부터 하나씩 처리한다.

가능한 것과 불가능한 것을 먼저 나눴다. 이 저장소에 붙어 있는 AI는 **EXAONE 텍스트
모델 하나뿐**이다 ([config.py](../backend/config.py)) — 비전 모델도, STT/TTS API 키도 없다.
그래서 "AI로 자동" 대신 브라우저 API나 사람이 직접 넣는 경로로 메운다.

### [x] A1. 사진에 인물 태그하기 (DEPICTS 공백 메우기) — 2026-08-20 완료

한 것:
- `PUT /api/media/{id}/persons` — 보낸 목록이 최종 상태가 된다 (더하기·빼기 모두)
- `POST /api/media/upload` 에 `person_ids` 폼 필드 (올릴 때 한 번에)
- `event_resolver.set_media_persons()` — detected_faces와 DEPICTS를 함께 맞춘다
- `_unlink_media_from_person()` — `remove_edge`가 두 노드 사이 관계를 **모두**
  지우므로, 뗄 때 NARRATED_BY가 함께 사라지는 것을 막는다
- CollectPage에 "이 사진에 누가 있나요?" 알약 (음성 제외)
- `tests/test_media_person_tags.py` 6개 — 6/6 통과
- 곁에서 고친 것: CollectPage의 `MEDIA_TYPE_LABEL`이 `image` 키를 보고 있어
  사진 알약에 `photo`가 그대로 노출되고 있었다

더하기만 두지 않은 이유: 등장 인물이 비공개 판정에 쓰이는데 잘못 지목한 사람을
뗄 수 없으면, 남의 사진에 자기가 영구히 붙는다.

가장 큰 기능 구멍이다. 업로드한 사진은 **어떤 인물과도 이어지지 않는다.**

- `detected_faces`는 [seed_from_metadata.py:180](../scripts/seed_from_metadata.py#L180)에서만 채워진다

- `link_media_to_person()` ([event_resolver.py:217](../backend/services/event_resolver.py#L217))은 호출부가 없는 죽은 코드

파급: 인물별 미디어 조회([media.py:181](../backend/routers/media.py#L181)), 등장인물 기준
비공개 판정([visibility.py:97](../backend/services/visibility.py#L97)), Chat 근거가 모두 시드
데이터에만 얹혀 있다. 가족이 새로 올린 사진은 그래프에서 고아가 된다.

할 일:
- 업로드에 `person_ids` (Form, 쉼표 구분) → 인물 노드 검증 → `detected_faces` + DEPICTS 엣지
- 보충 요청에 `person_ids` → 같은 처리
- confidence는 `user_input` / `confirmed` (사람이 직접 지목한 것이므로)
- CollectPage에 인물 고르는 UI

### [ ] A2. 음성을 글로 — 브라우저 STT

지금은 **타이핑 없이 음성만으로 답변할 수 없다.** 제출 버튼이 텍스트를 요구한다
([InterviewPage.tsx:507](../frontend/src/pages/InterviewPage.tsx#L507)). `transcript`로 저장되는 것은
사용자가 손으로 쓴 답변이다 ([InterviewPage.tsx:168](../frontend/src/pages/InterviewPage.tsx#L168)).

STT API 키가 없으므로 브라우저 Web Speech API(`SpeechRecognition`)로 녹음 중에
전사한다. 키·비용 없고 크롬에서 동작한다. 인식이 안 되는 브라우저에서는 지금처럼
타이핑으로 떨어진다.

할 일:
- [recorder.ts](../frontend/src/lib/recorder.ts)에 인식 결과 누적
- 전사문을 답변 입력란에 채우고 사람이 고칠 수 있게
- 브라우저가 지원하지 않으면 조용히 기존 경로

### [ ] A3. 영상 썸네일 · 길이

업로드한 video는 썸네일도([media.py:64](../backend/routers/media.py#L64) — photo만),
길이도 없다. 목록·그래프에서 영상은 회색 칸으로 뜨거나 원본을 통째로 로드한다.

보낸다 (서버에 디코더를 두지 않는다는 기존 결정을 따른다).

## C. 여기서는 안 한다 — 이유를 적어 둔다

| 항목 | 왜 |
|---|---|
| AI Vision 얼굴 인식 | 비전 모델이 없다. A1이 현실적 대체 |
| 지도 SDK (Leaflet/Mapbox) | 타일 네트워크·키·비용. A4로 버틴다 |
| webOS 실기기 | 기기·인증서 없음. [remote.ts](../frontend/src/lib/remote.ts)에 교체 지점만 남겨 둔다 |
| Export 작업 큐 | 시드 26MB에서 즉시 끝난다 ([export.py:3-5](../backend/routers/export.py#L3-L5)) |
| 벡터 검색 | 키워드 가중치로 goldset을 통과하고 있다 |
| Trust 화면에서 채점 실행 | 의도한 설계다. `POST /api/trust/run`은 있지만 몇 분 걸려서 화면에 안 붙였다 ([trust.py:3-5](../backend/routers/trust.py#L3-L5)) |
